# Warehouse Manager App

This project is a mobile-first Android and iOS app for a secondhand car parts marketplace warehouse.

## Run it

Open index.html in your browser, or use a live server extension in VS Code.

For the best mobile experience, use it in a browser and add it to your home screen.

## Notes

- The layout is designed for touch and small screens.
- It supports installable web app behavior through the manifest and service worker setup.
- It is built for warehouse management: staff attendance, task assignment, scheduling, and process control.
