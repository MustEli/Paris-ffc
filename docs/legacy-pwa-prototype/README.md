# Legacy PWA prototype (retired)

This was the original scaffold for the project: a static HTML/CSS/JS installable web app, originally a generic smart-home dashboard mockup that was relabeled "Warehouse HQ" without changing its actual UI. It does not implement any of the requirements in [../requirements/](../requirements/) and does not meet the "native app" / MDM white-listing requirement.

Kept for reference only. See [../architecture.md](../architecture.md) for the current stack (React Native/Expo + NestJS) that replaces it.
